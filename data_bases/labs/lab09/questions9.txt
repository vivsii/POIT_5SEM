1. Что такое точная и неточная выборки?
Точная выборка — это запрос, который возвращает либо одно значение (одну строку), либо ничего. Например, при выборе записи по первичному ключу, ожидается только одно значение. Если запрос возвращает больше одной строки, это приводит к ошибке.
Неточная выборка — это запрос, который возвращает более одной строки, когда ожидалось одно значение. В PL/SQL при неточной выборке возникает исключение TOO_MANY_ROWS.

2. Объясните действие конструкций WHEN OTHERS, WHEN TO_MANY_ROWS, WHEN NO_DATA_FOUND в секции исключения.
WHEN OTHERS — это универсальная конструкция для обработки всех типов исключений, которые не были явно указаны в блоке EXCEPTION. Обычно применяется для логирования или завершения работы программы в случае непредвиденной ошибки.
WHEN TOO_MANY_ROWS — срабатывает, если оператор SELECT INTO возвращает больше одной строки, что недопустимо для точной выборки.
WHEN NO_DATA_FOUND — срабатывает, если оператор SELECT INTO не возвращает ни одной строки. Это также может быть проблемой при выполнении запросов, где предполагается, что данные должны присутствовать.

3. Объясните назначение функций SQLERRM и SQLCODE.
SQLERRM — возвращает текст сообщения об ошибке, которое вызвало исключение. Используется для получения описания ошибки, произошедшей в PL/SQL-блоке.
SQLCODE — возвращает числовой код ошибки, которая произошла. Этот код может быть полезен для диагностирования и поиска в документации конкретных ошибок.

4. Что такое атрибут курсора? Перечислите все атрибуты курсора и объясните их назначение.
Атрибуты курсора — это свойства, которые возвращают информацию о состоянии курсора.

%FOUND — возвращает TRUE, если последняя операция FETCH успешно извлекла строку.
%NOTFOUND — возвращает TRUE, если последняя операция FETCH не извлекла строку.
%ISOPEN — возвращает TRUE, если курсор открыт.
%ROWCOUNT — возвращает количество строк, уже извлеченных оператором FETCH.

5. Объясните назначение конструкции RETURNING в операторах INSERT, DELETE, UPDATE.
Конструкция RETURNING используется для возврата значений столбцов, которые были изменены в результате выполнения операторов INSERT, DELETE или UPDATE, без необходимости выполнения отдельного SELECT-запроса. Это улучшает производительность, так как избегает дополнительного запроса к базе данных.

6. В чем отличие явного и неявного курсоров?
Неявный курсор автоматически создается при выполнении команды SELECT INTO, INSERT, UPDATE, или DELETE, и разработчику не нужно вручную его открывать, извлекать данные или закрывать.
Явный курсор объявляется явно в PL/SQL блоке. Разработчик должен самостоятельно управлять его жизненным циклом — открывать, извлекать строки (FETCH) и закрывать.

7. Объясните схему работы с явным курсором в PL/SQL-блоке.
Объявление курсора — задается запрос, который должен быть выполнен.
Открытие курсора (OPEN) — запрос передается базе данных для выполнения, и курсор становится доступным для чтения.
Извлечение данных (FETCH) — строки из результата запроса извлекаются по одной за раз.
Закрытие курсора (CLOSE) — освобождаются ресурсы, связанные с курсором.

8. Что происходит по команде OPEN курсора?
Когда курсор открывается, запрос передается на выполнение в базу данных, и создается активный результат (сет строк). Запрос не возвращает сразу все строки, они остаются в буфере базы данных до вызова FETCH.

9. Объясните особенность применения FOR-цикла при работе с явным курсором.
При использовании цикла FOR с явным курсором PL/SQL сам управляет всеми действиями по работе с курсором — открытие, извлечение строк и закрытие курсора происходит автоматически. Это упрощает код и минимизирует вероятность ошибок.

10. Для чего применяются параметры курсора? Где они указываются?
Параметры курсора используются для того, чтобы сделать курсор более гибким и передавать в него различные значения при каждом его вызове. Параметры указываются при объявлении курсора и передаются при его открытии.

CURSOR c1(p_faculty CHAR) IS 
    SELECT * FROM PULPIT WHERE FACULTY = p_faculty;

11. Что такое курсорная переменная? Как ее можно объявить?
Курсорная переменная — это переменная типа REF CURSOR, которая может ссылаться на разные запросы (в отличие от обычного курсора, связанного с конкретным запросом). Она позволяет динамически выполнять разные запросы, управляя результатами через одну и ту же переменную.

DECLARE
    TYPE cur_type IS REF CURSOR;
    my_cursor cur_type;

12. Что значит курсорный подзапрос?
Курсорный подзапрос — это подзапрос, который используется в основном запросе и возвращает несколько строк. Обычно используется в предложении WHERE или IN основного запроса.

SELECT * FROM TEACHER
WHERE PULPIT IN (SELECT PULPIT FROM PULPIT WHERE FACULTY = 'F01');

13. Объясните назначение конструкции CURRENT OF.
Конструкция CURRENT OF используется в операторах UPDATE и DELETE, чтобы модифицировать или удалить строку, которая была последней извлечена курсором.

UPDATE AUDITORIUM
SET AUDITORIUM_CAPACITY = AUDITORIUM_CAPACITY - 10
WHERE CURRENT OF my_cursor;

14. Для чего применяется псевдостолбец ROWID? Поясните его структуру.
ROWID — это псевдостолбец, который уникально идентифицирует строку в таблице на физическом уровне. Он указывает на физическое местоположение строки в сегменте таблицы и позволяет быстро находить и изменять строки.

Структура ROWID состоит из:

Объекта (Object ID)
Файла (Data File)
Блока (Block)
Номера строки (Row Number)
Пример использования:

SELECT ROWID, TEACHER_NAME FROM TEACHER;

15. Для чего применяется псевдостолбец ROWNUM?
ROWNUM — это псевдостолбец, который присваивает каждой строке возвращаемого набора данных уникальный порядковый номер. Это полезно для ограничения количества возвращаемых строк.

SELECT * FROM TEACHER WHERE ROWNUM <= 3;
