### 21. Основные глобальные объекты в Node.js и их предназначение

Node.js предоставляет несколько глобальных объектов, которые доступны в любой части программы без необходимости их импортировать. Вот основные из них:

- **`global`**: Это глобальный объект, аналогичный `window` в браузере. Переменные или функции, присвоенные `global`, становятся доступными во всей программе.
  
- **`process`**: Объект, предоставляющий информацию и управление текущим процессом Node.js. Он содержит данные об окружении, аргументах командной строки, переменных окружения и может использоваться для завершения процесса или отправки сигналов.

- **`console`**: Глобальный объект для вывода сообщений на консоль. Часто используется для отладки и ведения логов. Примеры методов: `console.log()`, `console.error()`.

- **`__dirname` и `__filename`**: Глобальные переменные, представляющие путь к каталогу, в котором находится текущий файл (`__dirname`), и полный путь к самому файлу (`__filename`).

- **`module` и `exports`**: Эти объекты используются для экспорта и импорта модулей в Node.js. `module.exports` используется для указания того, что модуль экспортирует, а `exports` — это сокращенная запись для экспорта объектов или функций.

- **`require`**: Функция, которая используется для импорта модулей в Node.js, будь то встроенные модули, модули из NPM или пользовательские модули.

- **`Buffer`**: Класс для работы с бинарными данными. Он позволяет работать с потоками данных или файлами в бинарном формате.

### 22. Поясните понятие «асинхронная функция»

Асинхронная функция — это функция, которая выполняется асинхронно, что означает, что ее выполнение не блокирует основной поток программы. Вместо того чтобы ждать завершения операции, программа продолжает выполнять другие задачи, а результат асинхронной функции будет обработан позже, когда она завершит свое выполнение. В Node.js широко используется асинхронный подход для операций ввода/вывода, таких как чтение файлов, работа с сетью и базами данных.

Асинхронные функции могут быть реализованы через:

- **Колбэки** (callbacks): Когда функция завершает выполнение, вызывается переданная функция-обратный вызов.
  
- **Промисы** (Promises): Механизм для работы с результатами асинхронных операций. Они имеют методы `then()` и `catch()` для обработки успешного завершения или ошибки.
  
- **async/await**: Более современный синтаксический сахар над промисами, который позволяет писать асинхронный код так, как если бы он был синхронным.

### 23. Поясните понятие стандартные «системные потоки»

Системные потоки (Standard Streams) — это три стандартных канала, которые операционная система предоставляет для взаимодействия с процессами:

- **stdin** (Standard Input) — стандартный поток ввода, который используется для получения данных от пользователя или другого процесса. В Node.js к этому потоку можно получить доступ через `process.stdin`.
  
- **stdout** (Standard Output) — стандартный поток вывода, который используется для отправки данных на консоль или другой процесс. В Node.js доступен через `process.stdout`.
  
- **stderr** (Standard Error) — стандартный поток вывода ошибок. Предназначен для вывода сообщений об ошибках и отладки, доступен через `process.stderr`.

Эти потоки позволяют взаимодействовать с процессом с помощью консольных команд, передавать данные на вход или получать результаты работы.

### 24. Поясните назначение функций process.nextTick, setImmediate, поясните в чем разница

#### `process.nextTick`

Функция `process.nextTick()` используется для отложенного выполнения кода. Она планирует выполнение колбэка на следующую итерацию цикла событий, но перед выполнением любых операций ввода/вывода, таймеров или других асинхронных задач. Эта функция позволяет вставить задачу в очередь для немедленного выполнения, гарантируя, что она будет выполнена до следующего этапа обработки событий.

Пример:
```javascript
process.nextTick(() => {
  console.log('Этот код выполнится перед любыми другими асинхронными операциями');
});
```

#### `setImmediate`

Функция `setImmediate()` планирует выполнение колбэка в следующей итерации цикла событий, но после завершения операций ввода/вывода, таймеров и других задач в текущей итерации. Таким образом, задачи, поставленные в очередь через `setImmediate()`, выполняются позже, чем те, что поставлены через `process.nextTick()`.

Пример:
```javascript
setImmediate(() => {
  console.log('Этот код выполнится после текущих операций ввода/вывода');
});
```

#### Разница между `process.nextTick` и `setImmediate`

- **`process.nextTick()`** выполняет колбэки **до** выполнения любых других асинхронных задач, даже если они уже находятся в очереди на выполнение. Это делает его идеальным для задач, которые должны быть выполнены сразу после текущей операции, но перед любыми другими асинхронными операциями.
  
- **`setImmediate()`** выполняет колбэки **после** завершения текущего цикла событий, что делает его полезным для выполнения задач, которые должны быть выполнены на следующем этапе обработки событий.

Очередность выполнения:
1. Код, переданный в `process.nextTick()`.
2. Ввод/вывод и другие асинхронные операции.
3. Код, переданный в `setImmediate()`.
