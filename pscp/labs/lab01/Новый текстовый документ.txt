9. Интернет — это глобальная система дополнительных компьютерных сетей, использующая стандартный набор протоколов TCP/IP для передачи данных между устройствами. 

10. Служба Интернет (интернет-сервис) — это определённый тип онлайн-сервиса или приложения, предоставляемого через Интернет. 

11. Узел сети Интернет — это любое устройство, подключенное к Интернету и имеющее уникальный IP-адрес, способное принимать, передавать или обрабатывать данные.

12. Клиент-серверное приложение — это программная архитектура, в которой задачи переключаются между двумя дополнительными компонентами:
Клиент — устройство или приложение, запрашивающее ресурс или данные.
Сервер — устройство или приложение, которое предоставляет ресурс или данные в ответ на запросы клиентов.

13. Сетевой протокол — это набор правил и стандартов, определяющих формат и порядок передачи данных по сети.

14. Основные свойства протокола HTTP.
без сохранения состояния: каждый запрос и ответ не зависят, сервер не сохраняет информацию о предыдущих запросах.
Текстовый : HTTP-запросы и ответы передаются в виде текстовых сообщений.
Протокол прикладного уровня : используется для передачи данных в Интернете, особенно для веб-приложений.
Использует клиент-серверную модель : клиент отправляет запросы, сервер отправляет ответы.
Методы.

15. Состав информации, пересылаемой в HTTP-запросе
Метод запроса (GET, POST и т.д.)
URI (адрес запрашиваемого ресурса)
Версия HTTP (например, HTTP/1.1)
Заголовки (информация о клиенте, тип данных и т.д.)
Тело запроса (если есть, обычно в POST-запросах, может сохраняться данные, например, form или JSON)

16. Состав информации, пересылаемой в HTTP-ответе
Версия HTTP (например, HTTP/1.1)
Код состояния (например, 200 — ОК, 404 — не найдено)
Заголовки ответа (информация о типе данных, соединении, кэшировании и т.д.)
Тело ответа (содержит данные, например, HTML-страницу, JSON-объект)

17. Группы заголовков HTTP
Общие заголовки (общие заголовки): касаются как запросов, так и ответов (например, Date, Connection).
Заголовки запросов (заголовки запроса): специфичны для HTTP-запросов (например, User-Agent, Accept).
Заголовки ответов (заголовки ответа): специфичны для HTTP-ответов (например, Server, Content-Type).
Заголовки сущностей (заголовки сущности): содержат информацию о теле сообщениях (например, Content-Length, Content-Encoding).

18. Определение понятия «Веб-приложение»
Веб-приложение — это программное обеспечение, доступное через веб-браузер и взаимодействующее с сервером через Интернет.

19. Определение понятий «Frontend» и «Backend»
Frontend — это часть приложения, с которым взаимодействует пользователь. Обычно это то, что отображается в браузере: HTML, CSS, JavaScript, пользовательский интерфейс (UI).
Бэкэнд — это серверная часть приложения, которая обрабатывает запросы, управляет базами данных и выполняет логику приложения. Бэкэнд написан на серверных языках, таких как Node.js, Python, Java.

20. Определение понятия «Кроссплатформенное приложение»
Кроссплатформенное приложение — это программное обеспечение, которое может работать на различных операционных системах (например, Windows, macOS, Linux) без необходимости адаптации для каждой из них. Примеры таких приложений: Google Chrome, Slack.

21. Общая схема веб-приложения
Клиент (Frontend) : взаимодействует с пользователем и отправляет HTTP-запросы.
Сервер (бэкенд) : получает запросы, обрабатывает их, взаимодействует с базами данных и получает результаты клиентского запроса.
База данных : хранит данные, использует приложения.
Схема:
Клиент <-> Сервер <-> База данных.

23. Понятие «Асинхронная операция»
Асинхронная операция — это операция, которая обеспечивает параллельный поток программы, что приводит к ее неблокированию. 

24. Основное назначение Node.js
Node.js — это среда выполнения JavaScript на сервере, позволяющая создавать высокопроизводительные серверные приложения.

25. Основные свойства Node.js
Асинхронная архитектура : неблокирующая модель ввода/вывода, позволяющая обрабатывать множество запросов одновременно.
Событийно-ориентированная модель : программа реагирует на такие события, как запрос или завершение операции.
Однопоточный : хотя Node.js работает в одном потоке, он может обрабатывать тысячи запросов одновременно благодаря асинхронной модели.
Масштабируемость : Node.js хорошо подходит для разработки приложений, требующих высокой производительности и масштабируемости.
Кроссплатформенность : Node.js работает на различных операционных системах, таких как Windows, Linux и macOS.
