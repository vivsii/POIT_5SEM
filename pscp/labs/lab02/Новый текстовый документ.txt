19. **Асинхронный запрос** — это запрос, который отправляется в фоновом режиме, без блокировки основного потока выполнения программы.

20. **AJAX** (Asynchronous JavaScript and XML) — это технология для создания асинхронных запросов к серверу из браузера, без необходимости перезагружать веб-страницу. 

21. **HTTP-заголовок Content-Type** определяет тип передаваемых данных в HTTP-запросе или ответе.

22. **Функция require** в Node.js используется для загрузки модулей (как встроенных, так и внешних).

23. **Модуль Node.js** — это отдельный файл или библиотека с функциями и объектами, которые можно использовать в других частях программы.

24. **Node.js built-in modules (Core modules)** — это встроенные модули, предоставляемые самой платформой Node.js. 

25. Модули, обеспечивающие работу с протоколом HTTP и файловой системой:
   - Для работы с **протоколом HTTP** используется модуль **`http`**. Он позволяет создавать HTTP-серверы и отправлять HTTP-запросы.
   - Для работы с **файловой системой** используется модуль **`fs`**. Этот модуль предоставляет методы для чтения, записи, удаления и других операций с файлами.

26. **npm** (Node Package Manager) — это менеджер пакетов для платформы Node.js.
