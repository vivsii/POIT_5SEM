### 1. Разница между функциями `FLOOR()`, `CEIL()`, `ROUND()` и `TRUNC()`

- **`FLOOR()`**: Округляет число **вниз** до ближайшего целого, всегда возвращает наибольшее целое, которое не больше исходного числа.
  - Пример: `FLOOR(3.7)` вернет `3`, а `FLOOR(-3.7)` вернет `-4`.
- **`CEIL()`**: Округляет число **вверх** до ближайшего целого, всегда возвращает наименьшее целое, которое не меньше исходного числа.

  - Пример: `CEIL(3.2)` вернет `4`, а `CEIL(-3.2)` вернет `-3`.

- **`ROUND()`**: Округляет число **до ближайшего целого** или до указанного количества знаков после запятой. Может округлять как вверх, так и вниз, в зависимости от дробной части.

  - Пример: `ROUND(3.567, 2)` вернет `3.57`, а `ROUND(3.4)` вернет `3`.

- **`TRUNC()`**: Обрезает дробную часть числа **без округления**. Можно указать количество знаков после запятой, до которых следует обрезать число.
  - Пример: `TRUNC(3.567, 2)` вернет `3.56`, а `TRUNC(3.567)` вернет `3`.

### 2. Встроенные функции для работы с датами

В PL/SQL существует множество встроенных функций для работы с датами. Вот основные из них:

- **`SYSDATE`**: Возвращает текущую системную дату и время.
- **`CURRENT_DATE`**: Возвращает текущую дату в часовом поясе пользователя.
- **`ADD_MONTHS(date, n)`**: Добавляет указанное количество месяцев к дате.
- **`MONTHS_BETWEEN(date1, date2)`**: Возвращает разницу в месяцах между двумя датами.
- **`NEXT_DAY(date, day)`**: Возвращает дату следующего указанного дня недели (например, следующее воскресенье после текущей даты).
- **`LAST_DAY(date)`**: Возвращает последний день месяца для указанной даты.
- **`TRUNC(date, fmt)`**: Обрезает дату до указанной части (например, до года, месяца).
- **`ROUND(date, fmt)`**: Округляет дату до ближайшего дня, месяца, года в зависимости от формата.
- **`EXTRACT(part FROM date)`**: Извлекает часть даты (год, месяц, день) из указанной даты.

### 3. Встроенные функции конвертации

Функции конвертации в Oracle используются для преобразования данных из одного типа в другой:

- **`TO_CHAR(expr, format)`**: Преобразует дату или число в строку с использованием заданного формата.
  - Пример: `TO_CHAR(SYSDATE, 'DD-MM-YYYY')` вернет текущую дату в формате строки.
- **`TO_DATE(char, format)`**: Преобразует строку в тип `DATE`, основываясь на переданном формате.

  - Пример: `TO_DATE('15-03-2023', 'DD-MM-YYYY')` вернет дату `15 марта 2023 года`.

- **`TO_NUMBER(char)`**: Преобразует строку в число.

  - Пример: `TO_NUMBER('1234.56')` вернет число `1234.56`.

- **`CAST(expr AS datatype)`**: Преобразует выражение в указанный тип данных.

  - Пример: `CAST('2023-10-14' AS DATE)` вернет дату.

- **`NVL(expr1, expr2)`**: Возвращает `expr1`, если оно не равно `NULL`, в противном случае возвращает `expr2`.

  - Пример: `NVL(NULL, 0)` вернет `0`.

- **`COALESCE(expr1, expr2, ...)`**: Возвращает первый непустой (не `NULL`) аргумент из списка.
  - Пример: `COALESCE(NULL, NULL, 'Привет')` вернет `'Привет'`.

### 4. Назначение встроенных функций `SQLCODE` и `SQLERRM`

- **`SQLCODE`**: Возвращает числовой код последней ошибки, произошедшей в PL/SQL-блоке. Если блок завершен успешно, то возвращает `0`.

  - Пример: В обработчике исключений можно использовать `SQLCODE`, чтобы получить код ошибки и выполнить соответствующие действия в зависимости от кода.

- **`SQLERRM`**: Возвращает текстовое сообщение последней ошибки, произошедшей в PL/SQL-блоке. Можно использовать вместе с `SQLCODE` для диагностики ошибок.
  - Пример: В блоке обработки исключений можно использовать `SQLERRM`, чтобы вывести сообщение об ошибке:
    ```sql
    EXCEPTION
      WHEN OTHERS THEN
        DBMS_OUTPUT.PUT_LINE('Error code: ' || SQLCODE || ' - ' || SQLERRM);
    ```

Эти функции особенно полезны для обработки исключений и диагностики ошибок в PL/SQL коде.
